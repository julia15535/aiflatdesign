# Product Brief — AI Flat Designer

## Что делаем

Telegram-бот, который вписывает мебель/декор из каталожных фото в фото комнат пользователя с сохранением visual identity товара (цвет, паттерн, форма) и контролем размера (±15%).

## Целевая аудитория и use case

**Платящие сегменты:**
- Ритейлеры мебели: Hoff, Divan.ru
- Производители: Аскона, Mr.Doors, IKEA-аналоги
- Застройщики (показ квартир с обстановкой)
- Дизайнеры интерьеров (presale)

**Use case:**
1. Пользователь грузит фото комнаты (любая — гостиная, спальня, кухня).
2. Грузит фото товара (как в каталоге Hoff/WB/Ozon — на белом фоне).
3. Указывает что заменить (sofa / armchair / bed / lamp / table / rug / wardrobe).
4. Опционально: размеры комнаты в метрах и размеры товара в см.
5. Получает фото комнаты с вписанным товаром за ~75 сек.

## Бизнес-цели MVP

Прототип на 6-8 дней даёт **факт ответ** на 3 вопроса:
1. Работает ли подход технически? (WOW ≥3.5/5 на medium сценах при следовании инструкциям)
2. Какой failure rate на реальных фото? (success rate ≥70% на medium)
3. Какова unit-экономика? (cost per successful gen <$0.30)

Если **GO** — переход к PRODUCT_FULL (продуктизация, B2B-pilot с одним из ритейлеров).

## Ценность для пользователей

| Пользователь | Польза |
|---|---|
| Маркетолог ритейлера | Красивые фото товара в реальной обстановке для лендингов/соцсетей без съёмки |
| Дизайнер интерьера | Клиенту показывают как будет выглядеть конкретный диван/кресло — выше конверсия |
| Застройщик | Демо-фото квартир с обстановкой → выше интерес покупателей |
| Покупатель мебели | "Примерить" товар в свою комнату до покупки |

## Ограничения MVP

- ✅ Один товар за раз (sofa или armchair, не "вся комната")
- ✅ Только Telegram (не web/mobile app)
- ✅ Long polling (без webhook)
- ✅ SQLite (не Postgres)
- ✅ Без авторизации (любой Telegram пользователь)
- ❌ Без личного кабинета, истории за >5 шагов
- ❌ Без оплаты (бесплатно в рамках теста)
- ❌ Без админки (статистика — SQL запросом)

## Что превратит это в продукт (после MVP)

- B2B integration: API для встраивания в каталог Hoff/Divan
- Личный кабинет с историей и пакетной обработкой
- Per-product LoRA для повышения точности воспроизведения
- Поддержка нескольких товаров в сцене
- Web app кроме Telegram
- Оплата (Stripe/Юкасса)
