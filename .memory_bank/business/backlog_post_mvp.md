# Backlog для после-MVP

Идеи которые отвергли для MVP, но имеют смысл когда продукт окажется рабочим и нужно будет масштабировать. Сюда копим — не теряем.

## 2026-05-11: Множественные фото комнаты по кругу

**Идея**: пользователь делает 5-10 фото комнаты «по кругу» (стоя в центре, поворачиваясь) → ИИ получает полный обзор → точнее оценивает размеры и форму комнаты → возможна 3D-реконструкция.

**Почему не в MVP**:
- В 5-10 раз дороже на оценку (множество vision-запросов = $0.02-0.03 на сессию вместо $0.005).
- Сложный UX — не каждый сделает аккуратные кадры без размытия (motion blur при повороте).
- Telegram сжимает картинки — несколько фото подряд = выше шанс что хотя бы одно убитое.
- **Главный архитектурный блок**: FLUX Fill Pro (программа генерации) работает с **одним** фото. Несколько фото = совсем другая архитектура (panoramic inpainting / 3D scene reconstruction) — в 10+ раз сложнее и за рамками MVP.

**Когда стоит вернуться**: после-MVP при работе с B2B-клиентом (ритейлер мебели). Тогда:
- 7-10 фото → 3D-модель комнаты → вписывание любых товаров каталога с любого ракурса.
- Это станет одним из ключевых преимуществ продукта.
- Технологии: panoramic stitching, NeRF / Gaussian Splatting, depth estimation (MiDaS).

**Связанные технологии**:
- MiDaS / Depth Anything — depth estimation из одного фото (можно использовать в Шаге 3 для уточнения)
- COLMAP / OpenSfM — структурированное восстановление из множества фото
- NeRF / Gaussian Splatting — 3D-представления сцены

**Триггер пересмотра**: B2B-пилот с ритейлером + спрос на «вписать товар в видеообзор квартиры».
