# Object Mapping: русский → английский

Файл: `ai/object_mapping.py`

## Зачем

Бот русскоязычный, пользователь пишет «обеденный стол», но для:
- Промптов OpenAI (slot estimation) — лучше работают с английскими словами
- GroundedSAM в Шаге 3 — принимает английский `mask_prompt`
- FLUX Fill Pro в Шаге 3 — английский prompt

Нужна нормализация пользовательского ввода.

## Интерфейс

```python
target_en, canonical_ru, is_known = to_english("обеденный столик")
# → ("dining table", "обеденный стол", True)

target_en, canonical_ru, is_known = to_english("банкетка")
# → ("bench", "банкетка", True)

target_en, canonical_ru, is_known = to_english("пуфик")
# → ("пуфик", "пуфик", False)   # не нашли — передаём как есть + флаг неуверенности
```

И список примеров для подсказки в боте:
```python
known_examples(10)
# → ["диван", "кресло", "обеденный стол", ...]
```

## Алгоритм

1. **Нормализация**: lower-case + замена `ё` → `е`
2. **Точное совпадение** в словаре синонимов
3. **Поиск по подстроке** (длина ≥4): «угловой диван» → находит «диван»
4. Если не нашли — возвращаем исходник + `is_known=False`

## Категории словаря

| Категория | Примеры |
|---|---|
| Диваны | диван, диванчик, софа, угловой диван |
| Кресла | кресло, пуф, банкетка |
| Столы | стол, обеденный стол, журнальный стол, письменный стол, консоль |
| Спальня | кровать, двуспальная кровать, тумбочка |
| Хранение | шкаф, гардероб, комод, стеллаж, полка, книжный шкаф |
| Стулья | стул, барный стул, офисное кресло |
| Освещение | лампа, настольная лампа, торшер, люстра, светильник |
| Декор | ковёр, зеркало, картина, постер, ваза, растение |
| Техника | телевизор, тумба под тв |

## Когда расширять

- Бенчмарк / beta-тест показал что пользователи часто пишут термин которого нет → добавить.
- Не плодим алиасы до бесконечности — оставляем 2-3 самых типичных варианта.
