# Onboarding (туториал)

При **первом** `/start` пользователь видит 4-страничный туториал с картинками. При повторном — сразу к делу. `/help` показывает туториал в любой момент.

## Подготовка assets — варианты

День 6 — Claude Code **обязательно** спрашивает пользователя:

```
Вариант A: Готовые из Unsplash + надписи в Pillow (час работы, бесплатно)
Вариант B: Сгенерить FLUX'ом + подобрать (~$0.40, быстро)
Вариант C: Композиты из реальных скриншотов в Figma (час, лучшее качество)
```

После выбора:
1. Создать первую версию assets
2. Скинуть 4 файла на оценку пользователю
3. Ждать фидбэка
4. Итерации до готового

⚠️ **Не пропускать этот шаг** — без хороших ассетов онбординг не работает.

## Текст экранов

```
👋 Я AI-помощник для вписывания товаров в интерьер.

Покажу как ваш товар (диван, кресло, лампа) будет смотреться в реальной комнате.

Полезно для:
• 📸 Маркетинга — красивые картинки в интерьере
• 🎨 Дизайна — клиент сразу видит результат
• 🏠 Продажи квартиры — обстановка повышает интерес

[Понятно, дальше →]
```

```
📷 ФОТО СЦЕНЫ (комнаты, в которую вписываем):
```

## State transitions

```
/start (first time)
  ↓ show_onboarding_step_1
[onboarding_step_1] ─ callback onb:next:2 → show_onboarding_step_2
  ↓
[onboarding_step_2] ─ callback onb:next:3 → show_onboarding_step_3
  ↓
[onboarding_step_3] ─ callback onb:next:4 → show_onboarding_step_4
  ↓
[onboarding_step_4] ─ callback onb:done → mark_user_onboarded + waiting_scene
```

## После онбординга

`mark_user_onboarded(user_id, username)` ставит `onboarded = TRUE` в `users`. При следующем `/start` туториал не показывается.

`/help` всегда показывает туториал — даже онбоарженным пользователям.

## Onboarding completion rate

Целевая метрика: ≥70% пользователей доходят до экрана 4. Если ниже — туториал слишком длинный или непонятный.

Аналитика:
```sql
SELECT
    SUM(onboarded) * 100.0 / COUNT(*) as completion_pct,
    COUNT(*) as total_users
FROM users
WHERE first_seen >= datetime('now', '-7 days');
```

## Анти-паттерны

- ❌ Длинные стены текста на одном экране — разбиваем на 4 шага.
- ❌ Картинка без подписей — без визуальных меток ✅/❌ юзер не считывает примеры.
- ❌ Заставляем ввести размеры до туториала — это вызывает дроп.
- ❌ Кнопка "Пропустить" — на MVP без неё, чтобы получить полный flow.
